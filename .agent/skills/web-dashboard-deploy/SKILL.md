# Web Dashboard Deploy & Output Standardization Skill

이 스킬은 PWAA 프로젝트의 단일 파일 웹 대시보드(`index.html`) 수정, 검증, GitHub Pages 배포 후 사용자를 위한 최종 안내 양식을 규정합니다.

## 핵심 의무 규격

웹 대시보드 관련 작업이 완료된 후 사용자에게 응답할 때:

2. **최종 URL 출력 라벨**: 반드시 정확히 아래 형식(불릿 + 클릭 가능한 링크)으로 작성합니다.
